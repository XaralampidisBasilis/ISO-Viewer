# Project Summary

ISO-Viewer is a browser-based medical volume visualization project focused on isosurface rendering for cardiac CT data. It is built with Vite, Three.js, WebGL2, custom GLSL shaders, and TensorFlow.js, and it runs as a self-contained viewer that can also be recreated or destroyed from `window.ISOViewer` for external integration. The application boots from `src/script.js`, initializes TensorFlow, validates WebGL2 support, loads NIfTI data, and constructs an `Experience` object that coordinates scene setup, camera controls, rendering, GPU preprocessing, world objects, statistics, and the lil-gui control panel.

The data pipeline is one of the project's defining features. A custom `NIFTILoader` reads compressed medical volumes, converts voxel values into typed arrays, normalizes spatial units, and exposes dimensions, spacing, and physical size. The `Computes` subsystem then builds a series of intermediate maps: a normalized volume map, an interpolation map, extrema data, an occupancy map, and several distance-map variants used for empty-space skipping. These maps are produced with TensorFlow.js-based GPGPU programs and uploaded as 3D textures, allowing the renderer to trade preprocessing cost for faster interactive ray marching.

Rendering happens inside a box-aligned shader material assembled from many GLSL chunks. The shader supports trilinear and tricubic interpolation, multiple marching and gradient strategies, optional Bernstein-based early rejection, configurable debug visualizations, bounding-box reduction, and several color maps for shading. The GUI exposes isovalue, interpolation, marching, gradient, skipping, colormap, and debugging options, while the camera uses spaceship-style navigation rather than orbit controls. This makes the viewer useful for both experimentation and demonstrations, especially when comparing visual quality, skipping methods, and performance tradeoffs on desktop GPUs. Around that core, the project includes custom first-person probe controls, sample cardiac, colon, and head datasets, publication assets, and reference papers. Overall, the repository reads like both a usable web viewer and a research prototype that turns advanced analytic isosurface techniques into an interactive browser experience.
