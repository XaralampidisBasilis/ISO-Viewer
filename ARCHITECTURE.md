# ISOViewer architecture

ISOViewer is a browser research viewer for implicit isosurfaces in scalar NIfTI volumes. The CPU loads the scan and coordinates builds and settings. TensorFlow.js runs custom packed WebGL2 preprocessing kernels. Three.js renders the nearest detected crossing with a GLSL 3 fragment shader on a box proxy. Vite bundles the ES module application and expands GLSL includes through `vite-plugin-glsl`.

## Scan preparation and resource ownership

`Experience.loadScan()` starts backend initialization and loading together, awaits `Computes.rebuild()`, then syncs the mesh and draws. [`Resources`](src/javascript/Utils/Resources.js) reads fetch or local file streams, tracks progress, and uses native gzip decompression when available. [`NIFTILoader.parse()`](src/javascript/Utils/NIFTILoader.js) validates a single scalar 3D grid and fixes byte order. Geometry uses storage axes and `pixDims` converted to meters (unknown units default to mm). Normalization uses raw stored voxel values.

[`sources.js`](src/javascript/sources.js) imports the bundled CTA preview (256 × 256 × 148) and detail (512 × 512 × 295) with factor `1` for both, verified from the source and asset headers. [`scripts/generate-cta-preview.mjs`](scripts/generate-cta-preview.mjs) makes the preview offline. Both use stored range `[0, 4095]`. Local files use resampled min/max and a scale chosen from the `410 × 410 × 236` voxel budget and `MAX_3D_TEXTURE_SIZE`. `validateGrid()` also checks `8 × blockedDepth` for octant maps, and loads that reframe the view can fall back to isotropic distance.

| Stage in `Computes.rebuild()` | Implementation and data |
| --- | --- |
| Scalar tensor | `VolumeMap.computeTensor()` converts to `Float32Array` and `[z,y,x]`. `GPGPUResizeTrilinear.ts` uses half-pixel centers when shape changes. For each axis `N′ = ceil(N × factor)` and `spacing′ = N × spacing / N′`. `GPGPUNormalizePacked.ts` normalizes and maps a constant range to zero. |
| Interpolation features | `InterpolationMap.computeTensor()` invokes `GPGPUInterpolationMapPacked.ts`. Logical shape `[z,y,x,2,2]` holds `[Δxx F, Δyy F, Δzz F, F]` in RGBA order, with clamped neighbors for second differences. `computeTexture()` creates a linearly filtered `RGBA16F` 3D texture. `getTextureData()` reads back half bits via native `Float16Array` conversion or `GPGPUToHalfFloatPacked.ts`. |
| Conservative block ranges | `ExtremaMap.computeTensor()` calls `computeExtremaMap()` in `GPGPUExtremaMapFusedPacked.ts`. Each block covers cells on a grid of `ceil((N+1)/B)` per axis, where `B` is block size. RG holds trilinear corner bounds. BA holds tricubic Bernstein bounds from separable axis transforms. The kernel pads both pairs by ±0.001, then clamps to `[0,1]`. |
| Threshold and skip data | `OccupancyMap` calls `GPGPUOccupancyMapPacked.ts` to test `min ≤ isovalue ≤ max` for the selected interpolant. `computeBoundingBox()` scans the same readback bytes used for texture upload and returns inclusive block bounds or `null`. The selected distance map is built from occupancy. |

TFJS outputs reach Three.js via synchronous `dataSync()` → typed arrays → `Data3DTexture` uploads. The extrema tensor persists for rethresholding. Scalar, interpolation, occupancy, and distance tensors are released after their consumers finish. `updateAcceleration()` updates existing buffers in place and marks them `needsUpdate`, and releases the previous distance texture on method switches. `rebuild()` disposes the previous map set on success and restores it on ordinary failure. `Experience.destroy()` aborts outstanding work and disposes maps, controls, mesh geometry, material, and renderer. Context loss stops rendering and requests reload.

`Experience.applySettings()` coalesces changes. Block size, scale, or a new scan rebuild the maps. Isovalue or interpolation recomputes occupancy, bounds, and the active distance map. A skip-method switch builds the newly selected distance map or reuses occupancy directly. Other settings update uniforms or defines, and `ISOViewer.sync()` requests material recompilation only when a define changes. `Configs` defaults to isovalue 0.35, block size 2, Csébfalvi tricubic interpolation, triquadratic B-spline gradients, cell DDA, grouped anisotropic skipping, Bernstein rejection, and occupied-box clipping.

## Block acceleration and texture contract

Active TypeScript kernels are under `src/javascript/Computes/Programs/`. Scalar distance maps use separable X/Y/Z Chebyshev transforms (`min` of candidates whose distances combine by `max`), with signed search directions for octants. Extended maps derive per-axis extents. All block textures use nearest integer fetches and no mipmaps.

| `SKIPPING_METHOD` | Active producer | Format and meaning |
| --- | --- | --- |
| 0 Occupancy | `GPGPUOccupancyMapPacked.ts` | `R8UI`, 0/1 candidate flag, one block per step |
| 1 Isotropic | `GPGPUIsotropicDistanceMapPacked.ts` | `R8UI`, shared Chebyshev radius capped at 255, zero means occupied |
| 2 Anisotropic | `GPGPUAnisotropicDistanceMapFusedPacked.ts` | `R8UI`, octant radius capped at 127, zero means occupied |
| 3 Extended isotropic | `GPGPUExtendedIsotropicDistanceMapPacked.ts` | `RG16UI`, negative/positive XYZ extents and occupancy |
| 4 Extended anisotropic | `GPGPUExtendedAnisotropicDistanceMapFusedPacked.ts` | `R16UI`, XYZ extents and occupancy per octant |

In [`chunks/functions/`](src/shaders/iso_viewer/chunks/functions), `sample_distance/`, `compute_octant.glsl`, and `unpack_uint5551.glsl` define the shader side. Among spatial axes, x varies fastest in the readback arrays. Anisotropic textures stack eight grids on z (`z + octant × blockedDepth`). Octant bits are x/y/z from low to high with nonnegative direction encoded as 1. The extended words use bits 15–11, 10–6, and 5–1 for X/Y/Z (each capped at 31) and bit 0 for occupancy. The shader clamps step counts to at least one and forms bounds using `step - 1` before crossing the region's exit face. Every skipped region along the ray must be free of candidate blocks.

## Fragment execution and numerical contracts

Paths below are relative to [`src/shaders/iso_viewer/chunks/`](src/shaders/iso_viewer/chunks). `vertex.glsl` maps the unit proxy and camera into grid space using `uCustomModelMatrix`. `fragment.glsl` imports `utils/`, `constants/`, `uniforms/`, `structs/`, and `functions/`, then executes ray setup → march → shade → optional debug. `structs/` carries `Ray`, `Box`, `Block`, `Cell`, `Trace`, candidate polynomials, `Hit`, and diagnostic state. Shader include bodies under `march/modules/` execute in `main()` and share state in that scope.

1. **Ray and coordinates.** `raycast/compute_raycast.glsl` intersects `[0,N]`, clamps entry to zero for an inside camera, and optionally clips to the occupied box. `ISOViewer.sync()` scales the world proxy by `N × spacing`. In grid space, texel centers are `i+0.5`, texture coordinates are `p/N`, cell coordinates are `floor(p+0.5)`, and block coordinates are integer cell coordinates divided by `B`. A cell with index `i` spans `i±0.5`. Inclusive occupancy bounds become `[min × B - 0.5, (max+1) × B - 0.5]` clipped to the volume. In normal rendering a miss on the enabled occupied box rejects the ray.
2. **Coarse traversal.** `march/modules/march_blocks/advance_blocks.glsl` shares single and grouped stepping between both fine traversals. `update_block.glsl` dispatches by skip method, and the four distance variants share `update_block/update_distance_block.glsl` (bounds inflated by 0.001 voxel). `functions/block_dda.glsl` caches adjacent face distances for occupancy and distance-map DDA. Larger skips and corrected coordinates restart the cache. Distance-map uniform stepping uses a fresh box exit intersection. Fine DDA enters using the saved `block.current_coords` via `startCellCoordsInBlock()` because `block.coords` has advanced.
3. **Cell DDA and roots.** `march/modules/march_cells/` advances exact cell segments. `functions/cell_dda.glsl` treats parallel exits as infinity, rechecks near ties against exact planes, and recomputes the winning face distance for polynomial endpoints. `functions/sample_value/` uses filtered alpha for trilinear. For Csébfalvi tricubic, it adds `Σ(½ qᵢ(qᵢ−1) ΔᵢᵢF)` with `q = fract(p−0.5)`. Along a ray within a cell, the trilinear residual is cubic, and the quadratic correction times cubic features yields a quintic. `update_cubic.glsl`/`update_quintic.glsl` reuse the previous endpoint sample. `intersected_cell/` reconstructs coefficients from samples, optionally rejects via Bernstein sign bounds, and selects sampled or hierarchical root testing. `utils/solvers/` and `compute_hit/` refine candidates in cell parameter `[0,1]` and take the smallest root. `end_cell.glsl` rejects hits outside the ray interval.
4. **Uniform stepping.** `march/modules/march_traces/` samples at `1/(5 × sum(abs(ray.direction)))`, with jitter phased from the ray or block entry by `snapTraceDistanceFloor()`. It detects adjacent residual sign changes and refines the bracket with a fixed 10 Neubauer iterations. Sampling can miss crossings that never produce a sampled sign change. `end_trace.glsl` applies the ray interval check.
5. **Shading.** Hit code orients gradient and Hessian from the sign of the ray derivative. `functions/compute_gradient.glsl` selects analytic, Sobel, or B-spline derivatives and scales by normalized spacing (pairwise products for the Hessian). `compute_curvatures.glsl` takes eigenvalues of `TᵀHT / |∇F|` in a tangent basis `T`. `shade/compute_shade.glsl` uses camera-aligned lighting, the isovalue palette, and gradient and curvature modulation. Default variants discard misses before shading and compile out diagnostic counters.

## Validation and performance

- `npm ci` then `npm run dev` runs the app. For a bundle check, `npm run build -- --outDir <absolute-scratch-directory>` avoids regenerating tracked `docs/`. Exercise changed shader defines in an accelerated WebGL2 browser because the bundle build only assembles the shader text. `package.json` exposes `dev` and `build`. The standalone `src/shaders/utils/solvers/test_cubic.glsl` and `test_quartic.glsl` fixtures are outside the active viewer include chain.
- `GUI.setupDebugBrowser()`, [`Utils/DebugViews.js`](src/javascript/Utils/DebugViews.js), and `debug/compute_debug.glsl` expose per-pixel hit state, distances, polynomial coefficients and roots, and traversal and fetch counts. Fetch counts track instrumented sampling calls. A selected diagnostic compiles a debug variant with discards disabled. `Configs.effectiveRootSolver` exposes alternate solvers through diagnostics, while normal rendering uses solver 1.
- [`Utils/Stats.js`](src/javascript/Utils/Stats.js) reports submitted FPS in 350 ms windows. **Measure FPS** enables continuous drawing at rest. Otherwise `Experience.update()` renders on invalidation. Motion uses 72% linear resolution for 160 ms after camera changes. Compare settled frames for performance. FPS measures frame cadence, and map `console.time` labels measure elapsed stage time including CPU work and synchronization.
- Preprocessing costs concentrate in extrema construction, distance passes, synchronous readbacks, and uploads. In the fragment path, focus on block and cell visits, feature fetches, candidate tests and root solves, and gradient/Hessian fetches. `PROJECT_OVERVIEW.md` records prior ad hoc occupancy checksum/bounds and first-hit comparisons. This reference was verified from source and asset headers. GPU limits, timing, and numerical agreement across browsers remain runtime checks.
